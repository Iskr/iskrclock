# IskrCLOCK v5.3

Современный будильник с онлайн радио и пользовательскими станциями.

## ✨ Возможности

### ⏰ Будильник
- Выбор времени (часы, минуты)
- Функция "подремать" (snooze)
- Нарастание громкости (fade-in)
- Регулятор громкости
- 17 встроенных радиостанций
- Пользовательские станции
- Полноэкранный режим
- Настройки (время, «подремать», нарастание) запоминаются
- Экран не гаснет, пока будильник включен (Wake Lock API)
- **🛡️ Отказоустойчивость** - при обрыве или зависании потока будильник сначала ~15 секунд переподключается, и только потом включает резервный сигнал; попытки продолжаются в фоне, и как только поток восстановится, снова играет радио

### 🎵 Пользовательские станции
- **📻 Радиопотоки** - MP3/AAC/HLS/.m3u/.m3u8
- **🎵 Локальные файлы** - MP3/FLAC/WAV (до 350MB)
- **📺 YouTube видео** - одиночные видео и плейлисты
- Управление плейлистами (добавление, удаление, изменение порядка)

### ⏲️ Дополнительные инструменты
- **Таймер** - обратный отсчет с пресетами, точный даже в фоновой вкладке
- **Секундомер** - с отметками кругов, переживает перезагрузку страницы
- **Калькулятор сна** - расчет оптимального времени для сна; нажмите на время, чтобы сразу поставить будильник

### 🌐 Полная интернационализация
- Русский 🇷🇺
- English 🇬🇧
- Выбор языка сохраняется на всех страницах

## 🚀 Технологии

- **HLS.js** - воспроизведение HLS потоков
- **IndexedDB** - локальное хранилище аудиофайлов
- **YouTube IFrame API** - встраивание YouTube
- **CORS Proxy** - обход CORS ограничений
- **CSS Animations** - плавные переходы FLOW

## 🎯 Использование

1. Откройте `index.html` в браузере
2. Выберите время будильника
3. Выберите радиостанцию или добавьте свою
4. Нажмите "Включить"
5. Наслаждайтесь! 🎉
